# Сайт репетитора

## Как собрать сайт

1. Установить Python 3 и библиотеку markdown (один раз):
       pip install markdown
2. Запустить сборку:
       python build.py
3. Открыть результат:
       cd public && python -m http.server 8000
   Затем открыть в браузере http://localhost:8000

## Как изменить цены и email

Откройте `config.json`, поменяйте числа и адрес, запустите `python build.py`.

## Как изменить текст

Текст лежит в `content/*.md`. Это обычные текстовые файлы.
Markdown-разметка:
    **жирный**, *курсив*, `код`, [ссылка](http://...)
    - элемент списка
    ## Заголовок

После правок — снова `python build.py`.

## Как опубликовать

Скопируйте содержимое папки `public/` на любой хостинг:
- GitHub Pages (залейте содержимое public/ в ветку gh-pages)
- Cloudflare Pages
- Netlify
- Или просто откройте index.html локально.

## Как сделать резервную копию

    git add .
    git commit -m "..."
    git push

Контент, шаблоны и код сохранены в репозитории.
Если сайт собран — папку public/ тоже можно сохранить куда-нибудь.
